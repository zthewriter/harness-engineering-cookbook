# The shared map, and where to go

The four shared recipes are the map of a harness. The steps for your job are in a persona folder.

| You | Go here |
| --- | --- |
| Vibe coder | [vibe-coders](../vibe-coders/README.md) |
| Technical writer | [technical-writers](../technical-writers/README.md) |
| Docs engineer | [docs-engineers](../docs-engineers/README.md) |
| Context engineer | [context-engineers](../context-engineers/README.md) |
| Developer advocate | [developer-advocates](../developer-advocates/README.md) |
| Developer | [developers](../developers/README.md) |

Writers, docs engineers, context engineers, and developer advocates document the product and publish it as a context pipeline. Developers connect the MCP servers that pipeline produces. Vibe coders use the same shape while they build an app.

A context server is RAG exported as an MCP server. Retrieval picks the passages. The MCP server is the endpoint each of those folders tells you to connect. [Choose a context server](choose-a-context-server.md) helps you pick one.
