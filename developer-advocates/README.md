# Developer advocates

You write the quickstart and the sample the harness will follow. Those are context, not just content. You publish them as an MCP server so a developer, and the agent in their editor, follows your steps instead of a tutorial for a different product.

A context server is RAG exported as an MCP server. The quickstart is a source. [Choose a context server](../recipes/choose-a-context-server.md) lists options. The export is what you put in the tutorial as "connect this."

| Recipe | You will have |
| --- | --- |
| [Put the quickstart on a server](01-quickstart-on-a-server.md) | A server that returns the current quickstart |
| [A tool that returns the current sample](02-tool-for-the-sample.md) | One custom tool for the sample you maintain |
| [Publish only the steps you followed](03-publish-what-you-followed.md) | A sample that cites the server you told readers to use |
