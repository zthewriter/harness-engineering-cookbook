# Example harness architectures

Each folder here is the whole harness for one kind of application: an architecture
diagram, what each part does, and starter files you can clone and fill in. The
[recipes](../recipes/README.md) explain the parts. These examples show them working
together in one system.

## Examples

The following table lists each example:

| Example | The application | Who it is for |
|---|---|---|
| [Docs site harness](docs-site/README.md) | A documentation site that people read and AI agents query over MCP | Technical writers, docs engineers, and context engineers |

## What every example contains

Every example folder has the following parts:

- A `README.md` with the architecture diagram, a text version of it, and a table
  that maps each part to its file and recipe.
- Starter files for the harness, with bracketed values to replace.
- A command to clone the folder, and the steps to adapt it to your stack.

To suggest another application, open a pull request with a folder that follows
the same shape.
