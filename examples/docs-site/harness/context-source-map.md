# Context source map

This page lists each kind of question readers ask, the source that answers it, and
who keeps that source current.

## Source map

The following table maps each question type to its source:

| Question type | Source | Owner | Freshness requirement |
|---|---|---|---|
| How to do a task | Published docs site, [docs URL] | Docs team | Within 1 hour of publish |
| API parameters and errors | API reference, generated from `[openapi path]` | API team | Each API release |
| Working code | Examples in `[examples path]` in the docs repository | Docs engineers | Each merge |
| What changed | Changelog page, [changelog URL] | Release owner | Each release |

## Questions no source answers

The context server answers from the sources above only. Questions about a reader's
own account, billing, or data get "not found" and a pointer to [support URL].
